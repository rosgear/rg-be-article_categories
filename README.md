## <img src="https://raw.githubusercontent.com/rosgear/rg-be-article_categories/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Модуль «Категории материала веб-сайта»

Модуль входит в состав Панели управления GePanel.

Модуль предназначен для создания, редактирования и администрирования категорий материалов (статей) веб-сайта, включая настройку их иерархии, атрибутов и параметров отображения.

### Скриншот
<img src="https://github.com/rosgear/rg-be-article_categories/blob/main/assets/help/grid.png?raw=true">

### Установка

Для добавления модуля в ваш проект, вы можете просто выполнить команду ниже:

```
$ composer require rosgear/rg-be-article_categories
```

или добавить в файл composer.json вашего проекта:
```
"require": {
    "rosgear/rg-be-article_categories": "*"
}
```
или скачать архив на [странице модуля](https://rosgear.ru/component/rg-be-article_categories/) в каталоге приложений RosGear.

После добавления модуля в проект выполните его установку в редакцию веб‑приложения с помощью Панели управления GePanel.

## <img src="https://raw.githubusercontent.com/rosgear/rg-be-article_categories/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Module «Website article categories»

The module is part of the GePanel Control Panel.

The module is designed for creating, editing, and administering categories of website materials, including setting up their hierarchy, attributes, and display parameters.

### Screenshot
<img src="https://github.com/rosgear/rg-be-article_categories/blob/main/assets/help/grid.png?raw=true">

### Installation

To add the module to your project, you can simply run the command below:

```
$ composer require rosgear/rg-be-article_categories
```

or add to your project's composer.json file:
```
"require": {
    "rosgear/rg-be-article_categories": "*"
}
```
or download the archive from the [module page](https://rosgear.ru/component/rg-be-article_categories/) in the RosGear application catalog.

After adding the module to the project, install it into the web application edition using the GePanel Control Panel.
